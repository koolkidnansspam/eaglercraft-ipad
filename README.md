## iPad / touch controls
Every client has an on-screen touch overlay that appears once you tap into the game.

- Left side: floating joystick (push fully forward to sprint)
- Right side: drag to look, tap to attack, hold to mine
- Buttons: JUMP, USE (right click), SNEAK (toggle), INV, DROP, VIEW, CHAT, PAUSE, hotbar 1-9
- Top-left: keyboard button to type chat or text fields, and settings (look sensitivity, fullscreen, hide controls)

The overlay is already built into each `.html` client. `ipad-controls.js` is just the readable source of that same script.
